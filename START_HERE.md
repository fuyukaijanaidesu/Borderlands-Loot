# Запуск Borderlands Loot

## Windows

1. Распакуйте архив в любую папку.
2. Установите Python 3, если он ещё не установлен: https://www.python.org/downloads/
   Во время установки включите **Add Python to PATH**.
3. Дважды щёлкните `start.bat`.
4. Приложение откроется в браузере по адресу http://127.0.0.1:8765/.

Оставьте открытым окно локального сервера, пока пользуетесь трекером.
Чтобы остановить сервер, закройте это окно.

## Что делает запускатель

`start.bat` запускает локальный HTTP-сервер только на `127.0.0.1` (на вашем компьютере) и открывает приложение в браузере. Он не устанавливает программу и не отправляет ваш прогресс на внешний сервер. Прогресс хранится в браузере.

Если порт 8765 уже занят, закройте программу, которая его использует, либо измените значение `PORT` в `start.bat`.

## Ручной запуск

Из папки проекта выполните:

```bat
py -3 -m http.server 8765 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:8765/.
